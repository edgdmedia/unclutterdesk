`Badge` is the uppercase pill for classification, not for state — use `StatusPill` for state.

```jsx
<Badge tone="pine">White-label</Badge>
<Badge tone="mint" height={18}>Desk</Badge>          {/* sidebar lockup */}
<Badge tone="tenantSolid">Selected</Badge>          {/* chosen service card */}
<Badge tone="secondary">Clinical psychology</Badge> {/* credentials */}
```

Gold is not an option here. Everything the old gold badge carried moved to `pine` or `mint`.
