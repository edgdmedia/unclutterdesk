`Logo` renders the mark, the full lockup, or the public "powered by" line.

```jsx
<Logo variant="lockup" size={30} assetBase="../../" />          {/* sidebar */}
<Logo variant="mark" size={76} assetBase="../../" />
<Logo variant="poweredBy" assetBase="../../" />                 {/* booking footer */}
```

"Booking powered by Unclutter Desk" is the ONLY Desk branding permitted on a tenant's public page.
