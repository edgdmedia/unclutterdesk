`AvatarChip` stands in for every person in Desk.

```jsx
<AvatarChip initials="AO" size={38} />
<AvatarChip initials="NM" size={38} tone="secondary" />   {/* Couples */}
<AvatarChip initials="JS" size={76} ring online />        {/* profile photo card */}
<AvatarChip initials="JS" size={32} tone="slate" />       {/* sidebar footer */}
```

Tone carries care-type meaning in rosters and session rows: `tenant` = Individual, `secondary` = Couples.
